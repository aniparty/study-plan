# 📋 学习计划清单（Study Plan）

一个帮助自己规划学习、坚持打卡的每日计划工具。基于「监督学习」理念设计，用游戏化的方式对抗拖延。

> 这是我独立开发的第一个完整项目，出发点很简单：**我想要一个能让我每天写下计划、完成后打勾、并看到自己坚持轨迹的工具**。与其找现成的 App，不如自己做一个。

## ✨ 在线体验

👉 **https://aniparty.github.io/study-plan/**

打开即用，数据保存在本地浏览器（localStorage），无需注册。

## 🎯 功能一览

### 核心：任务管理
- ✅ 添加 / 完成 / 删除任务，一键打勾
- ⏱️ 每个任务可设**预估时长**，自动统计「今日已学」「本周累计」分钟数
- 🔥 四象限优先级：紧急重要 / 重要不紧急 / 紧急不重要 / 不重要不紧急
- 📊 任务按优先级排序，实时显示本周四象限完成率

### 监督：复盘与坚持
- 🌙 **每日复盘**：晚上 22:00 后自动弹出，三问「学到了什么 / 遇到什么困难 / 明天怎么改进」，历史复盘可回看
- 📅 **连续打卡热力图**：GitHub 贡献图风格，颜色深浅代表当日完成量，可切换月份
- 🏆 **成就墙**：12 个成就自动解锁（首次完成、连续打卡 3/7/30 天、累计 10/50/100 个任务、单日 5/10 个、累计 10/50/100 小时）

### 仪式感
- 💬 每日一句名人名言，按日期轮换
